核心判断与推翻条件

  • 核心立场（基于 SEC Q3 2026 10-Q/8-K、Cognition 与 Fireworks AI 一手工程披露）：Cerebras 在推理端并不是 NVIDIA GPU 集群的全面替代品，而是面向「低并发（Batch Size 1–8）+ 重解码（Decode-heavy）+ 高时间价值交互」的片上 SRAM 带宽特种加速器。
  • 自然实验分水岭：同一 2.8T 混合专家底座 Kimi K3 上，Cognition（SWE-2.1）采用 NVIDIA 低价档（60 tok/s，2/10 美元/百万 token）与 Cerebras 极速溢价档（600 tok/s，5/25 美元/百万 token）双轨并行；Harvey（Harvey Tenet）选择 Fireworks AI + NVIDIA B300 / GB300 训推同栈 Inline 集群，以保住 99% 双状态前缀缓存命中率、Batch Invariance 与多租户弹性经济性。
  • 推翻条件 1：异构分离推理（GPU Prefill + WSE Decode）结合 CS-4 / CS-5 量产后，若能将 2.8T 私有定制权重的 Dedicated 专属托管单价压至接近 B300 / GB200 NVL72 水平（抹平 2.5 倍 溢价），Cerebras 将切入主流后训练底座。
  • 推翻条件 2：若 NVIDIA Vera Rubin + NVFP4 + 投机解码把 2.8T MoE 单流推高至 300+ tok/s 并稳压在 5 秒 心流窗口内，Cerebras 单流延迟溢价将被大幅压缩。
  • 推翻条件 3：若 2027 年 700 MW 机房交付或 Flex/Sanmina 10 倍 扩产不及预期，且 OpenAI（750 MW–2.0 GW）与 AWS 排他保底条款挤占中小客户额度，应用层商业化通道将进一步变窄。

二、自然实验对照：同一 Kimi K3（2.8T MoE）下 Cognition 与 Harvey 的基础设施分岔

Moonshot AI Kimi K3 拥有 2.8T 总参数、1M 上下文、69 层 Kimi Delta Attention (KDA) 线性注意力 + 24 层 Multi-head Latent Attention (MLA) 与 896 个 LatentMoE 专家（top-16 激活）（mat-fireworks-kimi-k3-rl@1）。两家应用龙头选用了截然不同的推理栈：

  • 状态耦合限制异构分离推理在长程法律场景的落地：跨池搬运必须同步迁移 MLA KV cache 与 69 层 KDA 循环/卷积状态并对齐 RL 版本；Fireworks Inline 虽均摊单流约 22 tok/s（128 并发总吞吐 2,834 tok/s），但依靠 ~99% 前缀复用和 ReplaySSM 投机解码把完整任务吞吐再提 65.05%。
  • 训推数值一致性决定生态粘性：Fireworks 通过 Batch Invariance + Router Replay (R3) 将同步 LoRA 训推 KL 散度压至 0.0008，XOR 权重增量把 1,024 GiB 检查点压缩 98% 至 20.3 GiB，自研 MoE Mega Kernel 较 DeepEPv2 提速 1.87–2.61×。

三、三维硬指标对比：Cerebras（CS-3 / CS-4 Nexus）vs NVIDIA（H200 / B200 / B300 / GB200 NVL72）

3.1 推理速度（Speed）：小批量 Decode 碾压 vs 长上下文与高并发反超

  • 访存带宽量级差：WSE-3（CS-3）将约 44 GB 存储全做在片上 SRAM，片上带宽达 21,000 TB/s (21 PB/s)；CS-4 搭载 3 颗 WSE-3T，片上互联带宽达 53.5 PB/s。对比 NVIDIA H200（141 GB HBM3e）4.8 TB/s、B200（192 GB）8 TB/s、B300 288 GB HBM、HBM4 约 22–23.3 TB/s。
  • 实测单流与小批量速度：gpt-oss-120b 在 Shared Inference 约 3,000 tok/s，Artificial Analysis 实测（high reasoning, 10k input）1,669 tok/s，领先 Azure（319 tok/s）、Baseten（293 tok/s）5 倍以上；2.8T SWE-2.1 Ultrafast 达 600 tok/s，Kimi K3.1 最高可达 2,000 tok/s。
  • Prefill 与高并发边界：单颗 WSE-3 仅 44 GB SRAM，大权重需多晶圆流水线配合 GPU Prefill + WSE Decode 分离推理（早期测试同 WSE 数量吞吐提 5 倍）；在数百高并发场景下，GB200 NVL72（72 卡聚合带宽 130 TB/s）靠权重读取摊销重占每 MW 经济性上风。

3.2 成本与单位经济（Cost & Unit Economics）：包机利用率陷阱

  • 价格与底层 TCO 锚点：Cognition 公开牌价上 Cerebras Ultrafast 较 GPU 标准档保持 2.5 倍溢价；Shared 共享低价（如 gpt-oss-120b 0.35 / 0.75 美元）仅限标准开源模型，私有后训练权重须签 Dedicated Inference。SemiAnalysis InferenceX 口径下 B200 / GB200 NVL72 折算单卡 TCO 约 1.73 与 1.86 美元/小时，大 MoE 上 GB200 NVL72 较单节点 B200 再降 35%–45%。
  • 包机利用率陷阱：Harvey 类工作日波峰波谷、100K+ 长上下文场景包租私有晶圆流水线，闲时固定折旧无法分摊会推高单任务成本；NVIDIA 允许「共享底座 + Multi-LoRA」或按分钟扩缩容。只有 Cognition（Windsurf + Devin）这类高频同步交互且能向客户收取 2.5 倍 速度溢价的场景，才消化得了 Dedicated 高固定摊销。
