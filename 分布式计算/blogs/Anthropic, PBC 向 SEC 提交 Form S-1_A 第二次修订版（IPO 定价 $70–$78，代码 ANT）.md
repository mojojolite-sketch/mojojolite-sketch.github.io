# Anthropic, PBC 向 SEC 提交 Form S-1/A 第二次修订版（IPO 定价 \$70–\$78，代码 ANT）

## 深度拆解与复核

- ==核心结论==：Anthropic, PBC（CIK `0002130357`，File No. `333-299633`）于 2026-11-10 提交 SEC 的 Form S-1/A Amendment No. 2（Nasdaq 代码 `ANT`，拟定价区间 \$70.00–\$78.00/股）不仅是一宗完全摊薄估值约 \$1.26 万亿–\$1.41 万亿的超级 IPO，更是检验全球 AI 算力供应链“供应商循环注资 + 表外长约锁单”商业闭环的法定总账本。招股书一方面披露了由按量消耗驱动的爆发式规模曲线（9M26 营收 \$332.4 亿、26Q3 单季 \$169.6 亿、10 月末 ARR 约 \$810 亿），另一方面也首次以法定口径摊开了延续至 2045 年的约 \$8,954 亿（\$895.4B）算力与电力采购/租赁承诺（未来 12 个月到期约 \$700 亿）及 26Q3 因高价补买短期算力而再度转负的营业利润（-\$5.67 亿）；与此同时，Google（100 亿）、NVIDIA（100 亿）、AMD（25 亿）等 7 家上游核心供应商通过同步 \$260 亿 Class N 私募直接以股本认购回流支撑下游算力需求，使 \$846 亿–\$937 亿 IPO 净募资实质转化为未来数年的算力基础设施预付款池。

#### 1. 场景与利益标注（IPO 招股书法定申报口径与卖方定价激励）
- 申报身份与治理边界：Anthropic, PBC 为特拉华州公益公司（Public Benefit Corporation），本次 Form S-1/A Amendment No. 2（Accession `0001628280-26-072484`）系公开发行路演定价阶段的法定注册文件。股权结构上设置四重分层：公开发行 Class A 股每股 1 票；创始人实体持有的单股 Class F 股锁定固定 50.1% 总投票权（无经济权益）；独立的长期利益信托（LTBT）持有单股 Class T 股（无经济权益），享有选举和罢免董事会多数席位的专属权力；上游供应商认购的 Class N 股则完全无投票权。
- 利益激励与口径拆解（本工作台核查）：IPO 定价区间 \$70–\$78 的核心叙事依托 9M26 收入同比跃升及单季突破 \$169.6 亿、10 月 ARR 约 \$810 亿的高成长指标，以及“经营现金流为正（9M26 +\$66 亿）”的轻资产表观；然而在分布式计算资产负债表视角下，算力硬件大量以云采购最低承诺与设备租赁形式放在表外，且管理层已主动提示“当短期需求超过多年期产能规划时，被迫采购昂贵短期算力会直接压缩营业利润率”。

### 观点与可反驳条件

- ==观点==：Anthropic Form S-1/A Amendment No. 2 本质上是一次“以超 \$2,160 亿备考现金池与 \$260 亿供应商股本绑定，兜底 \$8,954 亿跨周期算力刚性承诺”的金融工程。在分布式计算工程端，其四层异构采购体系（定制 ASIC/TPU + 三大公有云 + Akamai 纯 CPU 沙盒 + 1.7 GW 表后燃机排产）显著优于单一依赖 GPU 现货租赁的二线模型厂；但 \$260 亿上游循环注资与仅算计表内轻资产 CapEx 的现金流展示，也使上市后 4 个季度的核心矛盾锁定为“9M26 +\$66 亿经营现金流能否跑赢未来 12 个月约 \$700 亿算力履约兑付，以及短期现货补算力对营业利润率的侵蚀何时见底”。
- ==推翻条件==：
  1. ① 正向超预期推翻条件（经营杠杆全面兑现）：若 2027H1（27Q1–27Q2 季报）Anthropic 在单季营收维持 ≥25% 环比增长（ARR 站稳 \$1,300 亿以上）的同时，彻底摆脱高价短期算力补缺并实现单季 GAAP 营业利润稳定转正（非依赖剔除 SBC 的 Non-GAAP 调节），且全口径算力利润率提升至 ≥52%，则表明多芯片调度与 Anthropic Direct 租约已跨越爬坡折旧谷底，当前 \$1.26 万亿–\$1.41 万亿定价具备进一步上修空间。
  2. ② 负向证伪条件（表外算力承诺反噬现金池）：若 2027 年内企业客户 NRR 从约 900% 回落至 <200% 或开源/竞品价格战迫使主力 API 单价降幅无法被 Token 放量抵消，导致单季经营现金流持续低于当季约 \$175 亿（年化 \$700 亿）的刚性算力承诺兑付额并实质性消耗 IPO 募资本金，则“现金流自我造血覆盖长约”的核心假设将被证伪。
  3. ③ 供应链交付履约推翻条件：若 \$8,954 亿承诺中附先决条件的 \$2,138 亿（23.9%）算力/电力合同因第三方托管机房并网延期（如 Akamai 26Q3 已出现 \$30M CIS 收入顺延苗头）或设备担保违约触发大规模核减（2027 年底前按期通电交付率 <65%），将直接打断模型迭代节奏并拖累 Google/NVIDIA/AMD/Broadcom 等 \$260 亿私募方的高毛利算力出货兑现。
