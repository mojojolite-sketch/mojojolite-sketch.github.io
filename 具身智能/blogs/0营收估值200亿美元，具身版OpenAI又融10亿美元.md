# 0营收估值200亿美元，具身版OpenAI又融10亿美元

2026-10-28 · Physical Intelligence (arXiv:2604.15483) · Bloomberg · Penn PAL Lab · 有来源缺口

[本地原件归档](../../../raw/5648b8b15d1835ddb1da78d86fae0251f7cbcdceb6dcfbcd3996448282e2aa1b) · 固定材料版本 `digest-material-5648b8b15d1835ddb1da78d86fae0251f7cbcdceb6dcfbcd3996448282e2aa1b@1` · [一手原站](https://arxiv.org/abs/2604.15483)

## 深度拆解与复核

- ==核心结论==：Bloomberg 于 2026-10-27 传出 [Physical Intelligence](../entities/companies/Physical%20Intelligence.md)（PI）正洽谈新一轮至少 $1B（10 亿美元）融资、投后条件估值约 $20B（较去年 11 月 $5.6B 涨至 3.6 倍，较 2026 年初 $11.5B 接近翻番），引发「零商业营收却高估于已披露 $1 亿 ARR 对手 Skild AI」的定价争议；本工作台交叉核查 π0.7 原论文（arXiv:2604.15483）、Pi API Beta 与 Penn PAL Lab 独立真机测试后认为，PI 溢价交易的核心期权在于以跨本体泛化与 10 月上线的托管 API 生态卡位「通用具身模型底座」，但独立测评下早期模型 π0 在开放场景平均任务进度仅 42.3%，且面临 NVIDIA GR00T 与 Google Gemini Robotics「免费大脑送芯片/算力」的直接压制，高估值尚未跨越商业兑现门槛。

#### 一、业务切口与核心机制

触发线索为微信公众号 `量子位ROBO`（`AI4ROBO`，作者杰西卡，2026-10-28）对 Bloomberg 融资消息的编译与产业背景梳理，与站内已归档的 Pi API Beta / MEM 架构分析及 [《π0.5 (pi0.5): A Vision-Language-Action Model with Open-World Generalization (arXiv:2504.16054)》](%CF%800.5%20%28pi0.5%29_%20A%20Vision-Language-Action%20Model%20with%20Open-World%20Generalization%20%28arXiv_2504.16054%29.md) 形成商业估值与技术实测互补：

1. 纯软件「通用具身大脑」定位与顶级学术班底：PI 于 2024 年成立于旧金山，放弃重资产自研机器人硬件，专注以视觉语言模型（VLM）为底座叠加连续动作生成训练视觉—语言—动作模型（VLA），适配第三方多样化机械臂与双臂系统。创始团队汇聚 CEO Karol Hausman（前 Google / Google DeepMind 前沿机器人科学家、斯坦福兼职教授）、[Sergey Levine](../entities/people/Sergey%20Levine.md)（UC Berkeley 教授、BAIR 强化学习领军）、[Chelsea Finn](../entities/people/Chelsea%20Finn.md)（斯坦福大学助理教授、曾师从 Levine）、Lachy Groom（Stripe 早期员工、硅谷知名天使投资人，曾投 Figma、Notion、Ramp）以及前 DeepMind 研究骨干 Brian Ichter。
2. 技术迭代与 2026-10 开发者平台转型：从 2024-10 发布 π0（2025-02 开源 openpi）一路迭代至 π0-FAST、π0.5、π0.6（结合 MEM 长短期记忆）与 2026-04 发布论文的 π0.7（[arXiv:2604.15483](https://arxiv.org/abs/2604.15483)），并在 2026-10 推出 Pi API Beta。外部团队可上传自有遥操作数据、在 PI 托管云端算力上微调 π0.7 并接入托管推理网关（如 Weave Robotics 将 PI 模型用于 $7,999 家庭叠衣机器人 Isaac 0，Almond 用 Pi API 在 4 天内训练双臂机器人的去毛刺工序），试图解决单一团队无法承担全行业长尾工位数据采集的瓶颈。

#### 二、核心数据核查、口径纠偏与工程边界

场景与利益披露：本条目中文触发稿件为量子位ROBO 编译报道，其融资数字源自 Bloomberg 匿名信源（2026-10-27 传闻）；同时 PI 官方在推出 Pi API Beta 时曾公开发布警示称「真实环境中的机器人应用绝非易事，无论是建筑施工、机器人手术还是仓储自动化，攻克每一个领域都需要倾注一家完整公司的资源」。该表态既有降低下游盲目预期、引导开发者依托 Pi API 底座的生态叙事功能，也客观反映了长尾工程收敛难度。

- ✅ 算力开支与开发者生态的双向绑定（本工作台核查）：正如 PI 联创此前对社区披露，公司大部分融资直接投入 GPU 算力集群而非快速变现团队。开放 Pi API Beta（对接 Chef Robotics、Formic、Almond 等 11 家早期伙伴）既是为了解决自身数据采集覆盖不足，更是试图在各垂类机器人公司之间构建「微调数据回流飞轮」——但前提是商业客户不介意核心工位操作轨迹沉淀到 PI 云端底座模型中。
- ⚠️ 「免费大脑」巨头夹击边界（本工作台推断）：与纯模型实验室在数字领域靠订阅收费不同，[NVIDIA](../entities/companies/NVIDIA.md)（免费开源 GR00T 绑定 Jetson 端侧与算力卡）与 Google（Gemini Robotics 绑定云与基础设施）有充分动机把机器人基础模型作为「硬件/云算力的零毛利引流层」。若客户发现 PI 的收费 API 无法在可靠性上大幅甩开免费开源底座（如 GR00T N1.7 或 MolmoAct2），PI 在 $20B 估值下收取高毛利软件授权费的商业逻辑将承压。

### 观点与可反驳条件

- ==观点==：若按传闻 $20B 条件估值成交，Physical Intelligence 的定价隐含了市场把「通用机器人软件层」比照数字大模型平台给予 50 倍于两年前种子轮的期权溢价；但从 Penn PAL Lab 42.3% 的开放任务进度、π0.7 开启子目标世界模型后达 127ms 乃至更高的推理延迟，以及 NVIDIA GR00T / Google Gemini Robotics 的免费基建替代压力来看，Pi API Beta 能否在 12 个月内跑出不依赖一次性定制服务、可跨客户复用的高毛利 ARR，是区分「基础设施垄断」与「高估值算力烧钱期权」的试金石。
- ==推翻条件==：
  1. ① 商业 ARR 与留存证伪：若 PI 在 2027-Q4 前公布 Pi API 商业化成绩，确认付费活跃企业客户突破 50 家、纯模型微调与推理订阅 ARR 达到 $50M 以上且已有客户在无 PI 驻场工程团队干预下完成产线级持续复购，则本文对其商业化滞后于 $20B 估值的质疑将被推翻。
  2. ② 开放生态被免费模型取代证伪：若至 2027 年底，开源或免费模型（如 NVIDIA GR00T 后续版本、Ai2 MolmoAct 系列及开源社区模型）在第三方真实操作基准（如 RoboArena）上的零样本与微调平均进度全面追平同期闭源 π 系列 API，且 PI 本轮 $20B 融资传闻被迫折价落地或延期交割，则「具身版 OpenAI 软件税」估值叙事将被证伪。
