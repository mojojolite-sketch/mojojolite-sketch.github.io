### 二、 剥离宣传后的真实技术栈定位与库内坐标

1. ✅ 原生动作预训练与能力保留机制（本工作台核查）：WALL-OSS-1.0 从 Qwen3.5 基座出发，通过改进版 X-Tokenizer（arXiv:2606.14752）把异构单/双臂与底盘动作离散化后与图文数据混合自回归预训练（Stage 1 通用 VLM 能力保留率 79.2% vs 基座 79.4%，显著优于 GR00T N1.7 的 5.1% vs 70.4% 与 WALL-OSS-0.5 的 45.1% vs 71.9%），Stage 2 再扩展为 MoT 流匹配动作专家。这种「先统一语义动作表征、再接管纠错闭环」与同批 [X2Real](https://arxiv.org/abs/2609.27449) 评测中获得 67.55/100（超越 Lingbot-VLA-2.0 的 40.94）及 OOD 移动操作均值 44.17（vs π0.5 24.83）的趋势一致。
2. ⚠️ 与 Agent 框架的协同边界（本工作台推断）：自变量同期开源了借鉴 DeepSeek Harness 的三层框架 `XR Harness`（System 2 规划 XR Brain + System 1 执行 WALL-OSS-1.0 XR Cerebellum + System 0 RAP 硬件协议），恰恰反向印证了当前 VLA 本体（50.67%–55.1% 零样本成功率、20.76 Open-vocab 分）尚不具备独立应对开放长程任务的能力，仍高度依赖外部大模型 Agent 拆解指令并由 Watcher/Monitor 闭环兜底。

### 观点与可反驳条件

- ==观点==：量子位《具身行业，终于等来了自己的通用智能时刻》一文属于典型的中高度标题党与多实验混剪稿件——它把自变量机器人 WALL-OSS-1.0 确实突出的「预训练多模态保留率（79.2%）」「10 小时产线快速适配（90% 跨站迁移）」与「XInfer 并发服务（2,231 parcels/h）」包装成了「55.1% 无微调通吃开放世界、榜单甩开 Agent 大模型」的伪共识叙事；从投研视角看，WALL-OSS-1.0 的真正生态位是当前国内工程化完成度靠前的==低样本工业部署微调底座与 XR Harness 底层动作执行器==，而非已跨越具身通用智能临界点的零样本通才。
- ==推翻条件==：
  1. 第三方盲测真机零样本跃迁：若在完全由独立第三方（非自变量或其关联作者维护）主持的 RoboDojo-RealWorld 18 项真机全榜与未见工具/变形铰接任务中，未微调且未挂载外部 System-2 大模型规划器的 WALL-OSS-1.0 旗舰开源权重实现 >= 80% 完整任务成功率（且在 RoboDojo 全榜非作弊轨道稳居前二），则本文对其「距离通用智能尚远」的界定将被推翻。
  2. 旗舰开放与商业无微调复用实证：若自变量在 2027 年上半年向社区完整开源 WALL-OSS-1.0 全参数旗舰及 Gen/AR 权重，且外部物流/制造客户无需收集那 10 小时产线微调数据、仅凭 WALL-API-1.0 零样本调用即稳定实现与现网部署同等节拍和良率，则「本质仍依赖任务微调基座与系统 Agent 兜底」的判断将被证伪。
