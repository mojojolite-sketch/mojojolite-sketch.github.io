# 百亿具身独角兽破壁，玩家集体涌向它的牌桌

## 深度拆解与复核

### 一、 口径与利益披露及信源分层

- 口径与利益披露：触发来稿为微信公众号「量子位（QbitAI）」2026-11-26 18:10 发布的行业评述《百亿具身独角兽破壁，玩家集体涌向它的牌桌》（作者林方舟，URL：https://mp.weixin.qq.com/s/t7d9MrlwIxUF0xD6wpXJNw），属二手媒体转述稿；其核心叙事引自一目科技（YIMU Technology）创始人兼 CEO 李智强 2026-11-26 发布的公司成立十周年全员信，但该全员信原文截至 2026-11-26 尚未在公开互联网及一目科技官网全文挂出。本工作台穿透抓取一目科技官方网站（https://www.yimu.ai/zh-cn/ecosystem 、https://www.yimu.ai/zh-cn/sensing 、https://www.yimu.ai/zh-cn/models 与 https://www.yimu.ai/zh-cn/about）作为一手实证基准。商业激励方面，一目科技于 2026 年 7 月完成超 10 亿元人民币 E 轮融资（投后估值突破 100 亿元，庚辛资本任长期财务顾问），十周年节点对外释放生态升级与「百亿估值、行业成本最低之一」等信号，核心商业诉求是在视触觉传感器批量交付之外，向主机厂、集成商与具身模型团队争取上肢平台与数据标准主导权；其公关稿与官网均未披露分产品收入、量产良率及单台 BOM 成本。

### 二、 技术架构拆解、官网参数核验与全员信对照

一目科技官方门户将技术栈定义为 R-AGI 统一生态系统（ACT：感知 SENTRA → 推理 WORLD ACTION MODEL → 执行 DEXTRA），而量子位转述的十周年全员信则披露了面向生态伙伴的 YIMU xEco（Dexterous Manipulation Ecosystem）四件套命名。两套一手与二手口径的映射对照如下：

| 架构层级 | 全员信转述命名（YIMU xEco） | 一目官网一手命名（R-AGI） | 官网已披露工程规格与机制细节 |
| :--- | :--- | :--- | :--- |
| 高维感知硬件 | 仿生视触觉传感器 | SENTRA T0（具身触觉）与 SENTRA E0（微光谱） | Sentra T0：官网标称全球最薄可商用视触觉传感器（公开技术资料披露整机厚度压至 3 mm 以内，传统光学方案通常超 20 mm），5 mN（0.005 N）三维力分辨率，8 ms 最快响应速度，微米级深度感知，超百万次按压耐久性，IP65 防水防尘，无惧温漂与无空间解算盲区；Sentra E0 延续微光谱水质检测（约 60 g，24V DC / 50 mA，0.1 s 响应，1% 精度，TOC/COD/NTU 检测） |
| 灵巧操作上肢 | YIMU xHand（灵巧手 + 机械臂上肢本体） | DEXTRA（类人执行终端） | 官网定位为「将触觉传感器与机械臂、灵巧手一体化设计」，前置解决安装空间、感知覆盖与结构/电气/算法三层适配；Dextra 与 YIMU xHand 均未披露自由度、整手质量、额定握持负载与单手售价 |

### 三、 核心指标核查与商业边界剖析

- ✅ 一手官网物理底座与「10 年周期、700+ 专利、双业务线」口径互证（本工作台核查）：一目科技 2016 年 5 月成立至今走过 10 年产业周期，创始人李智强（卡内基梅隆大学博士）早期以微流体与微光谱芯片（Sentra E0）起家，近三年将研发重心转向具身智能视触觉（Sentra T0）。官网披露硕博研发人员占比超 50%，拥有南京 APEX 精密制造工厂与苏州超级数采基地，并与全员信提及的「全球布局 700 多项知识产权」以及医疗实验室配胶、汽车/家电线缆电池柔性装配场景互相印证。
- ⚠️ 「YIMU xEco / YIMU xHand」与官网命名时间差及规格书缺口（本工作台核查）：截至 2026-11-26，一目科技官网（yimu.ai）仍以 R-AGI / SENTRA / WORLD ACTION MODEL / DEXTRA 作为对外产品栏位，尚未上线 YIMU xEco、YIMU xHand、YIMU xStudio、YIMU xWorld 的独立文档页、SDK 仓库或公开 API 计费标准。换言之，全员信中的「x 系列」目前停留在战略发布与媒体预热口径，尚无可供第三方开发者直接核验的软件下载包或硬件参数表。
- ⚠️ 「全行业成本最低之一」的量纲与损耗分母复核（本工作台推算）：全员信宣称一目科技通过芯片、材料、光学与算法四层全栈自研，已将产品压至全行业成本最低之一，但未公布 Sentra T0 单颗出厂价与 Dextra/xHand 上肢总成报价。视触觉方案除了光学模组与芯片 BOM，量产部署还必须计入弹性体接触层在高频抓取摩擦下的撕裂老化更换频率与重新标定工时；官网虽标称 Sentra T0 具超百万次按压耐久性，但「垂直按压寿命」与真实工业装配中带剪切滑移摩擦（线束插拔、电池压装）的「硅胶表皮磨损周期」属不同物理量纲，在未公开第三方良率与单颗定价前，不能依据单一芯片自研直接推导出全生命周期总拥有成本（TCO）领先。
- ⚠️ 「不自研大脑、不自营数据资产」三条边界与苏州数采基地的现实张力（本工作台推断）：全员信提出三条战略边界——不自研通用大脑模型（开放接口接入第三方大脑）、不自营数据资产业务（只提供格式与工具支持数据回流）、不直接下场做行业应用运营。但官网同时重资产自建苏州「华东具身超级数采基地」并推进自有 World Action Model 训练。本工作台推断，一目科技保留了「以触觉为中心的小脑动作原语与物理反馈模型」，仅将通用语义规划（VLA 大脑）和终端现场交付让渡给客户与集成商。这一架构依赖一个前置前提：第三方大模型厂商（例如采用端到端 VLA/WAM 路线的本体厂）愿意把高频接触控制与技能封装权留在一目科技的 xStudio 栈内，而非直接读取 Sentra T0 原始张量并入自有端到端网络。

### 观点与可反驳条件

- ==观点==：==一目科技十周年升级 YIMU xEco，本质上是百亿估值后为跳出「单一传感器 BOM 压价陷阱」做出的上肢平台卡位：凭借 3 mm 以下可量产的 Sentra T0 光学触觉硬件与南京 APEX 制造能力，向下捆绑机械臂与 YIMU xHand（Dextra）交付标准化上肢，向上以 YIMU xStudio / World Action Model 承接跨本体小脑技能，并将通用大脑与行业运营切割给合作伙伴==；然而从「官网仍为 R-AGI/Dextra 宣传占位、xHand 规格与单价缺失、以及主机厂/模型厂倾向端到端直控原始触觉张量」来看，一目科技能否跨越「标准零件商」成为上肢生态底座，关键瓶颈集中在第三方开发者与大脑厂商是否愿意让渡技能抽象层，而非单纯的光学硬件指标。
- ==推翻条件==：
  1. 若截至 2027 年底，一目科技仍未公开上线 YIMU xStudio SDK、开发者社区文档及 YIMU xHand（Dextra）完整量产规格与公开报价，且其公开新增客户订单中超 80% 仍为单独采购 Sentra T0 传感器模组而非整套上肢与技能平台，则本文关于「一目科技有望跑通上肢标准生态平台」的演化路径判断被推翻。
  2. 若 2027 年头部具身大模型厂商（如 Physical Intelligence、NVIDIA GEAR 或国内头部人形本体厂）在主流工业装配与灵巧操作部署中普遍采用直接读取第三方触觉传感器原始图像/力矩信号接入端到端 VLA 策略，完全绕开独立小脑 Skill 中间层，且一目科技自研 World Action Model 未获 3 家以上外部主机厂批量商用集成，则本文关于「独立触觉小脑 Skill 层具备长期平台议价权」的假设被推翻。
  3. 若一目科技在后续公开测试或客户验收报告中披露 Sentra T0 在真实 3C/汽车线束插拔产线下的单颗批量售价低于行业电容/霍尔阵列方案 30% 以上，且弹性体表皮带剪切滑移寿命突破 50 万次无需重标定，则本文关于「视触觉方案在成本与耐磨损耗上仍具显性边界」的审慎约束条件需相应修正。
