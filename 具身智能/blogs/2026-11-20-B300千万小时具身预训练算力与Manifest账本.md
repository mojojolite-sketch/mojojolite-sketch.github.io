# 千万小时具身预训练算力（B300 集群）与 Manifest 内存账本

2026-11-20 · 工作台基于 NVIDIA GB300 NVL72 规格与已归档工程口径的第一性原理成本核算

## 千万小时预训练四档算力测算

计算基准采用 10,000,000 小时物理采集数据（360 亿秒，约 4.3 亿 episodes，AV1 压缩存储 25–100 PB），对齐 NVIDIA B300 单卡规格（FP8 稠密 4.5 PFLOPS、BF16 2.25 PFLOPS、288 GB HBM3e；GB300 NVL72 整柜 72 卡 B300 + 36 颗 Grace CPU，提供 20.7 TB HBM3e 与 17 TB CPU RAM，即每 4-GPU 托盘约 944 GB CPU 内存、整柜功耗约 135 kW）；单 Epoch 在 30 天内跑完，FP8 取 40% MFU（约 1.80 PFLOPS/卡）：

| 模型与序列配置 | 单卡需求与 NVL72 机柜数 | 30 天单 Epoch 算力成本与功耗 | 备注与对应工程约束 |
| :--- | :--- | :--- | :--- |
| S1 抽帧 VLA（7B, 300 tok/s, 10.8T tok） | 97 卡 B300（1.4 柜） | `$0.3M–$0.4M` | 仅覆盖低频抽帧语义对齐，易丢接触时序 |
| S2 主流压缩 WAM（14B, 1,000 tok/s, 36T tok） | 702 卡 B300（9.8 柜） | `$2.3M–$3.0M`（1.32 MW） | 参照 [GR00T 2 Turbo](GR00T%202%20Official%20Technical%20Release_%20Scaling%20World-Action%20Models%20on%20402%2C000%20Hours%20of%20Human%20Video%20with%20X-Adapt%20%26.md) 压缩路径 |
| S3 前沿 WAM（30B, 1,000 tok/s, 36T tok） | 1,505 卡 B300（20.9 柜） | `$4.9M–$6.5M`（2.82 MW） | 叠 3–5× 研发消融常备 2,000–5,000 卡（`$10M–$30M`） |
| S4 稠密三视角 WAM（30B, 3,000 tok/s, 108T tok） | 4,861 卡 B300（67.5 柜） | `$15.8M–$21.0M`（9.11 MW） | 多路未经空间 token 压缩的稠密视频训练上限 |

## 倒挂排序：为什么采集与 I/O 先于 GPU 算力撞墙

对比文本大模型（GPU 算力占成本大头），千万小时具身预训练的六大瓶颈呈现结构性倒挂：

1. 数据采买与入湖吞吐：按当前真机与高质量第一视角混合单价估算，千万小时总采买需 `$50M–$200M`；按 [Dyna Robotics](../entities/companies/Dyna%20Robotics.md) 约 44 万小时/周的极限入湖清洗速率，单是完成入湖就需 22.7 周（约 5.2 个月）。
2. Manifest CPU 内存墙：4.3 亿条 episode 索引若沿用单机内存映射（`mmap`），单节点 Manifest 内存占用高达 2.18 TB，直接击穿 GB300 单托盘约 944 GB 的 CPU RAM 上限，迫使工程架构切向 Lance 或 Parquet 分布式分片。
3. 随机帧解码与跨区流量税：随机抽帧打破连续视频 GOP 顺序读，在 [Generalist AV1 视频压缩路径](Generalist%EF%BC%9A%E7%99%BE%E4%B8%87%E5%B0%8F%E6%97%B6%E6%95%B0%E6%8D%AE%E7%9A%84infra.md)下触发 5–10× 解码 I/O 放大；若 100 PB 级别存储遭遇单轮跨洲拉取，云出口带宽费用可达 `$5M–$9M`。
4. 热存储年费：25–100 PB 热存储年租金约 `$4.5M–$25.2M/年`，成为常备集群外的固定沉没成本。
5. GPU 预训练算力：S2–S3 主流配置下仅占总预算小头。
6. 本地自动化标注：沿用 FLORA 规模测算，千万小时级本地标注约需 2.5 万 GPU-天（60 万 GPU-h），成本仅 `$1.5M–$3.0M`。

综合来看，单小时纯采集费之外，「高良率串联工序」（如 [Maxinsights](../entities/companies/Maxinsights.md) 强调的 99%^4 良率与边际信息增益）以及 AV1 关键帧直读/离线 Latent 预处理才是决定千万小时真实可用成本的关键。

### 观点与可反驳条件

- 观点：只要端侧世界—动作模型继续受益于时空压缩（如 `Wan 2.2 VAE` 等 4×16×16 级压缩），具身基模规模竞赛的第一壁垒就不在 GPU 购买量，而在「合规真机/第一视角数据供应链 + PB 级随机解码与分布式 Manifest 基建」。
- 推翻条件：
  1. 若高倍率空间/时间 VAE 压缩在多指精密触控中证明不可用，迫使全行业退回 3,000–5,000 tok/s 全像素多视角与百 B 级稠密在线仿真 RL，GPU 算力支出将重新压倒采集成本。
  2. 若纯仿真合成管线或通用视觉大模型在 18 个月内将高良率等效真机采集成本压低至 `$1/h` 以下，且无需外部百万小时视频入湖，上述 `$50M–$200M` 采买倒挂账本将被推翻。
