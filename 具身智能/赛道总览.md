# 具身智能

以机器人完成真实物理任务为中心，追踪策略模型（VLA/WAM）、数据管线、全身运控（S0）、视触力闭环与商业化部署的逻辑演变。

## 当前研究重点与核心判断

- **核心矛盾**：具身智能的瓶颈不是“单次演示能否成功”，而是**换任务、换环境、换本体后，能否在真实节拍（UPH）、良率、错误恢复与单位工时经济性（ROI）上通过验收**。
- **架构收敛（S2 → S1 → S0）**：
  1. **S2 规划层**：从自回归 VLM 串行吐坐标转向**世界—动作模型（WAM，[DreamZero](https://arxiv.org/abs/2602.15922)）**与**单步并行视觉图元解码（[NVIDIA VFlash](blogs/%E8%8B%B1%E4%BC%9F%E8%BE%BE%20VFlash%EF%BC%9AJim%20Fan%E5%AE%A3%E5%91%8A%E2%80%9CSystem-1%E8%A7%86%E8%A7%89%E6%96%B0%E6%97%B6%E4%BB%A3%E2%80%9D%EF%BD%9C%E6%A8%A1%E5%9E%8B%E6%8F%9F%E9%80%9F12%E5%80%8D.md)）**，消除边缘端 75%–87% 的解码延迟并降低 42.6% 的 3D 轨迹误差。
  2. **S1 数据与接口层**：从昂贵真机遥操作与粗糙人手模仿转向**跨本体物理表征对齐（[UVTA 触觉外骨骼](blogs/%E8%A7%A6%E8%A7%89%E7%81%B5%E5%B7%A7%E6%93%8D%E4%BD%9C%E6%9D%80%E5%87%BA%E4%B8%80%E5%8C%B9%E9%BB%91%E9%A9%AC%EF%BC%9A%E4%BA%BA%E7%B1%BB%E8%A7%A6%E8%A7%89%E6%95%B0%E6%8D%AE%E7%BB%88%E4%BA%8E%E8%A2%AB%E8%A7%84%E6%A8%A1%E5%8C%96%E5%9C%B0%E7%94%A8%E8%B5%B7%E6%9D%A5%E4%BA%86%EF%BC%9F.md)、[EgoScale](blogs/%E4%B8%93%E8%AE%BFDanfei%20Xu%EF%BC%9A%E4%BA%BA%E7%B1%BB%E6%95%B0%E6%8D%AE%E6%98%AF%E4%BC%AA%E8%A3%85%E6%88%90%E5%8F%A6%E4%B8%80%E7%A7%8D%E5%BD%A2%E5%BC%8F%E7%9A%84%E6%9C%BA%E5%99%A8%E4%BA%BA%E6%95%B0%E6%8D%AE.md)）**、**低成本亚秒级视频编译（[Perceptron $29/h API](blogs/%E6%AF%8F%E5%B0%8F%E6%97%B629%E7%BE%8E%E5%85%83%EF%BC%8Cegocentric%20video%E8%BD%AC%E4%B8%BA%E6%9C%BA%E5%99%A8%E4%BA%BA%E8%AE%AD%E7%BB%83%E6%95%B0%E6%8D%AE.md)）**与**合成仿真闭环（[FLORA 稠密奖励 + MolmoBot](blogs/Where%20Physical%20AI%20Is%20Heading.md)）**。
  3. **S0 运控与力控层**：动捕+视频课程缩放构建通用小脑（[SONIC](blogs/%E4%B8%93%E8%AE%BF%E7%BD%97%E6%AD%A3%E5%AE%9C%EF%BC%9A%E5%85%B3%E4%BA%8ESONIC%E5%85%A8%E8%BA%AB%E6%8E%A7%E5%88%B6%E6%A1%86%E6%9E%B6%E7%9A%84%E8%AE%BF%E8%B0%88.md)、[GAE](blogs/Human%20Data%20EP06%E2%80%94Mocap%2BVideo%EF%BC%9AGAE.md)、[HuB](blogs/Human%20Data%20EP05%E2%80%94Video%EF%BC%9AHUB.md)、[VideoMimic](blogs/Human%20Data%20EP04%E2%80%94Video%EF%BC%9AVideoMimic.md)），配合 6 轴力与微米视触觉毫秒级闭环攻克接触后装配失效（[ForceVLA2](https://arxiv.org/abs/2603.15169)、[瞬恒 SynDexy C1](blogs/%E6%8A%8A%E5%B7%A5%E4%B8%9A%E7%B2%BE%E5%AF%86%E5%B7%A5%E5%BA%8F%E4%BA%A4%E7%BB%99%E6%9C%BA%E5%99%A8%E4%BA%BA%EF%BC%9A%E7%9E%AC%E6%81%92%E6%99%BA%E8%83%BDSynDexy%20C1%20%E5%AE%8C%E6%88%90%E9%A6%96%E6%AC%A1%E5%B0%8F%E6%89%B9%E9%87%8F%E4%BA%A4%E4%BB%98.md)）。
  4. **商业终局**：基础模型向公有云巨头与中系开源权重（LingBot / Xiaomi-Robotics-1）收敛，Pi 转向算力与 API 底座；受制于 20 自由度灵巧手约 30 万次抓握寿命瓶颈，短期结构化工位优先，**真正的护城河在 RaaS 部署闭环与跨客户高复用 Adaptor 工具链**（[Alex Zheng 旧金山报告](blogs/Where%20Physical%20AI%20Is%20Heading.md)、[Momenta 招股书镜像](blogs/%E5%A4%A7%E6%A8%A1%E5%9E%8B%E8%83%BD%E4%B8%8D%E8%83%BD%E5%90%83%E6%8E%89%E5%85%B7%E8%BA%AB%EF%BC%8C%E8%A6%81%E5%85%88%E7%9C%8B%E8%83%BD%E4%B8%8D%E8%83%BD%E5%90%83%E6%8E%89Momenta%E3%80%82.md)）。

### 五问总览（2026-11-06；`question-embodied-reusable-reliability@3`）

1. **未解决的问题**：换任务、换环境、换本体后，如何在真实节拍、良率、错误恢复与单工位 ROI 上通过验收？核心受制于五个缺口：语义理解≠物理接触控制；预训练常见场景可靠性与困难状态覆盖率权衡；人类单目姿态追踪（25–31 mm）与异构重定向（1–14 mm）累积误差；多指灵巧手约 30 万次寿命硬伤（工业高频拣选约 1 个月损耗）；高硬件 Capex 阻碍客户一次性买单。
2. **当前解决设想**：S2 层以 WAM（DreamZero）预测行动物理后果，以 Flash Primitive Decoding（VFlash）单步并行草拟完整 2D/3D 轨迹；S1 层以穿戴式触觉外骨骼（UVTA）、低成本亚秒级视频 API（Perceptron）及合成仿真+FLORA 稠密奖励构建物理监督；S0 层以动捕/视频课程（SONIC/GAE/HuB/VideoMimic）与视触力三态融合（ForceVLA2/SynDexy C1）兜底全身平衡与精密接触；商业层以 RaaS 订阅（失败成本 < 节省人工工资）与高复用 Adaptor 工具链跨越部署鸿沟。
3. **主导概念的实质与演变**：从工业机器人的“固定工位+专用工程”，经 RT-2/OpenVLA/$\pi_0$ 的“网页语义先验迁移”，演化为 **S2（认知/世界预测）— S1（中间图元/潜动作/Adaptor）— S0（高频全身与力控）** 三层解耦与中间接口上移；数据范式从“机械复制人类姿态轨迹”转向“迁移底层接触物理规律（UVTA/EgoScale）与合成仿真闭环（MolmoBot/Eka）”。
4. **被修正及新概念产生的原因**：最终 checkpoint 压缩困难状态覆盖率（斯坦福 2611.01565）；纯视觉在接触遮挡与微米阻力下失明（插偏/插过头/插不到底）；自回归 VLM 逐坐标解码造成数秒盲区与连锁漂移，且传统投机解码因 1 bin 坐标微偏即触发验证坍塌（DFlash 每次仅提交 2.2 token）；人手追踪误差与灵巧手 30 万次寿命无法直接支撑高强工业负荷。
5. **必须逐项否定或限定边界的早期错误**：演示≠部署；平均成功率≠产线可靠性；语义泛化≠物理泛化；力不能早期注入预训练 VLM（ForceVLA 消融成功率 0%）；纯无触觉人类数据不能直接驱动真机灵巧操作（UVTA 消融纯人数据成功率 0%）；自回归 VLM 输出分布≠视觉几何规划上限；模型领先≠商业护城河（系统工程隐性技术债与现场 Adaptor 复用率决定交付成败）。

### 节点机制与证据锚点

- **P / A / B / C · 三大物理与工程瓶颈**：高层 VLM 自回归生成轨迹占边缘推理总耗时 75%–87%（[VFlash](https://research.nvidia.com/labs/lpr/vflash/)）；接触瞬间手爪遮挡且纯视觉无法感知微米阻力（[SynDexy C1](blogs/%E6%8A%8A%E5%B7%A5%E4%B8%9A%E7%B2%BE%E5%AF%86%E5%B7%A5%E5%BA%8F%E4%BA%A4%E7%BB%99%E6%9C%BA%E5%99%A8%E4%BA%BA%EF%BC%9A%E7%9E%AC%E6%81%92%E6%99%BA%E8%83%BDSynDexy%20C1%20%E5%AE%8C%E6%88%90%E9%A6%96%E6%AC%A1%E5%B0%8F%E6%89%B9%E9%87%8F%E4%BA%A4%E4%BB%98.md)）；单目手部追踪（25–31 mm）与重定向（1–14 mm）误差叠加（[Alex Zheng](blogs/Where%20Physical%20AI%20Is%20Heading.md)）；且物理闭环下的动作分块、通道顺序与控制同步等周边工程变量直接左右评测结果（[Kundalia 隐性技术债](blogs/%E7%A6%BB%E5%BC%80%E8%8B%B1%E4%BC%9F%E8%BE%BE%E5%88%B0Dream%20Labs%E5%BD%93API%E8%B4%9F%E8%B4%A3%E4%BA%BA%E5%90%8E%EF%BC%8C%E4%BB%96%E5%8F%91%E7%8E%B0%E5%86%B3%E5%AE%9A%E6%9C%BA%E5%99%A8%E4%BA%BA%E8%83%BD%E5%8A%9B%E7%9A%84%E8%AF%B8%E5%A4%9A%E5%9B%A0%E7%B4%A0%E4%B8%AD%EF%BC%8C%E6%A8%A1%E5%9E%8B%E5%8F%AA%E5%8D%A0%E5%BE%88%E5%B0%8F%E4%B8%80%E9%83%A8%E5%88%86.md)）。
- **S2 · 世界—动作模型（WAM）与并行视觉规划**：[DreamZero](https://arxiv.org/abs/2602.15922) 联合预测未来视频与动作（7Hz 闭环，10–20 分钟视频跨本体迁移）；[NVIDIA VFlash](blogs/%E8%8B%B1%E4%BC%9F%E8%BE%BE%20VFlash%EF%BC%9AJim%20Fan%E5%AE%A3%E5%91%8A%E2%80%9CSystem-1%E8%A7%86%E8%A7%89%E6%96%B0%E6%97%B6%E4%BB%A3%E2%80%9D%EF%BD%9C%E6%A8%A1%E5%9E%8B%E6%8F%90%E9%80%9F12%E5%80%8D.md)（`digest-material-4850e501621a8d3c5d234dacad88a714335f51f887decb795af7616286387b95@1`）以 5 层双向 537M 扩散草稿器结合工具调用边界/坐标槽位对齐，跳过逐 token 验证单步并行生成 2D/3D 轨迹，在 Jetson Thor 上实现规划解码 12–42 倍提速、全流水线 5.1 倍提速（3.55s→0.70s），3D 轨迹误差（ADE）降 42.6%，驱动 Cosmos-Predict2.5 WAM 成功率从 61.0% 升至 70.2%。
- **S1 · 数据金字塔编译与合成仿真闭环**：[EgoScale / Danfei Xu](blogs/%E4%B8%93%E8%AE%BFDanfei%20Xu%EF%BC%9A%E4%BA%BA%E7%B1%BB%E6%95%B0%E6%8D%AE%E6%98%AF%E4%BC%AA%E8%A3%85%E6%88%90%E5%8F%A6%E4%B8%80%E7%A7%8D%E5%BD%A2%E5%BC%8F%E7%9A%84%E6%9C%BA%E5%99%A8%E4%BA%BA%E6%95%B0%E6%8D%AE.md) 用 2 万+小时第一视角视频预训练感觉运动先验并做效果驱动重定向；[Perceptron Egocentric 1.0](blogs/%E6%AF%8F%E5%B0%8F%E6%97%B629%E7%BE%8E%E5%85%83%EF%BC%8Cegocentric%20video%E8%BD%AC%E4%B8%BA%E6%9C%BA%E5%99%A8%E4%BA%BA%E8%AE%AD%E7%BB%83%E6%95%B0%E6%8D%AE.md) 以 $29/h API 输出亚秒级子任务时间线与免标定双手 3D 网格（误差 5.21 mm）；[UVTA](blogs/%E8%A7%A6%E8%A7%89%E7%81%B5%E5%B7%A7%E6%93%8D%E4%BD%9C%E6%9D%80%E5%87%BA%E4%B8%80%E5%8C%B9%E9%BB%91%E9%A9%AC%EF%BC%9A%E4%BA%BA%E7%B1%BB%E8%A7%A6%E8%A7%89%E6%95%B0%E6%8D%AE%E7%BB%88%E4%BA%8E%E8%A2%AB%E8%A7%84%E6%A8%A1%E5%8C%96%E5%9C%B0%E7%94%A8%E8%B5%B7%E6%9D%A5%E4%BA%86%EF%BC%9F.md) 以穿戴式 20 维 FSR 触觉外骨骼动捕+触觉预测世界模型实现 84% 真机灵巧操作；[Noitom ModalityNet](blogs/ModalityNet%EF%BC%9A%E5%B0%86%E4%BA%BA%E7%B1%BB%E6%95%B0%E6%8D%AE%E7%BC%96%E8%AF%91%E4%B8%BA%E5%8F%AF%E5%AD%A6%E4%B9%A0%E7%9A%84%E6%9C%BA%E5%99%A8%E4%BA%BA%E6%95%B0%E6%8D%AE.md) 用影棚高精真值训练野外数据补全编译器；[Alex Zheng 报告](blogs/Where%20Physical%20AI%20Is%20Heading.md)揭示硅谷主航道进一步转向自动化 3D 场景 + NVIDIA FLORA（1/125 成本稠密奖励）+ 离线 RL（Ai2 MolmoBot / Eka VFA 纯仿真零样本抓取反超 $\pi_{0.5}$），辅以[斯坦福动作误差分布筛选](blogs/%E6%96%AF%E5%9D%A6%E7%A6%8F%E5%AE%8B%E8%88%92%E7%84%B6%E5%9B%A2%E9%98%9F%E6%8F%90%E5%87%BA%E6%9C%BA%E5%99%A8%E4%BA%BA%E9%A2%84%E8%AE%AD%E7%BB%83%E8%AF%84%E4%BC%B0%E6%96%B0%E6%8C%87%E6%A0%87%EF%BC%9A%E7%94%A8%E5%8A%A8%E4%BD%9C%E8%AF%AF%E5%B7%AE%E5%88%86%E5%B7%AE%E9%80%89%E6%A8%A1%E5%9E%8B%EF%BD%9C%E5%8F%AA%E7%9C%8B%E9%AA%8C%E8%AF%81%E6%8D%9F%E5%A4%B1%EF%BC%8C%E5%8F%AF%E8%83%BD%E9%94%99%E8%BF%87%E6%9B%B4%E5%A5%BD%E7%9A%84%E5%BE%AE%E8%B0%83%E8%B5%B7%E7%82%B9.md)兼顾预训练覆盖率与可靠性。
