03 · 三场决定未来三年方向的商业正面碰撞

STRATEGIC CLASHES

碰撞 A · NVIDIA vs AMD × World Labs

怎么打：NVIDIA 已经把 Isaac Lab 3.0 + Newton（MJWarp + STEEL）+ SimFoundry + GR00T 2 + Thor 连成唯一端到端物理+算力闭环；AMD 掏 $8.2B 吞下 World Labs，是用全球最强通用 3D 场景资产生成器（Atlas）给 Instinct / ROCm 引流。

商业看点：短期 World Labs 只是“上游资产工厂”，不能替代物理引擎；只有当它通过自研或合作（如共投 Genesis AI）接上可微/柔体接触求解与机器人端侧中间件时，才能真正威胁 NVIDIA 算力税。

碰撞 B · Tesla FSD v15 / Waymo vs 具身 S1

为什么车比手早一步：Tesla 靠百万真车在半颗 AI4 上跑通实时 GTA 式世界重渲染，Waymo 改写 Genie 3 生成 Camera+LiDAR——证明了「避碰物理」的神经世界模型已工业化。

看穿边界：自动驾驶只需知道 2D 宏观平面不撞谁，而 Optimus 灵巧手与桌面操作需要毫秒级「主动压紧、微滑移、摩擦与柔体变形」。视觉像素多逼真都不等于力控闭环，这是 Tesla 必须单独留重算力 AI5 给 Optimus 的根本原因。

碰撞 C · 仿真 RL 独角兽 vs 百万小时真世界派

表面对立，实则分层融合：哪怕是喊出最重仿真口的 Genesis AI（外采 20 万 h Ego）与 NVIDIA（40.27 万 h Human-1M + 8 项 SimFoundry r=0.92 评测），实操都已经证实：纯仿真取代不了真世界物理接触，真机采数也铺不起 1,000 个 OOD 房间与每日千次归因评测。

商业结果：纯卖“通用刚体仿真数据”的中间商溢价被压穿（光轮被迫保持 80% Ego），真正留下利润的是真世界高良率采数 + 400× 级仿真评测平台 + 垂类交钥匙运营。
