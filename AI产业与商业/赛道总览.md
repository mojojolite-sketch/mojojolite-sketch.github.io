# AI产业与商业

追踪跨赛道的 AI 市场渗透、基础模型与应用控制点之间的价值分配及商业模式演化。

## 当前研究重点

- 企业级 AI 渗透中继 vs 资本信贷分水岭：[Anthropic 2026-11-10 IPO 路演与 SEC Form S-1/A](blogs/Anthropic%20%E8%B7%AF%E6%BC%94%E7%BA%AA%E8%A6%81%E5%85%A8%E6%96%87%2BPPT.md)（[主体档案](entities/companies/Anthropic.md)）首次提供前沿模型厂法定审计账本——9M26 收入 \$332.42 亿（10 月 ARR 约 \$810 亿）、~80% 按量 API 计费与约 900% 净收入留存率（NRR）证实企业工作流替换仍处加速换挡中继；但全口径算力利润率（43%）远低于仅计付费推理的 GAAP 毛利率（85.52%），叠加延续至 2045 年的 \$8,954 亿 表外算力租赁承诺及上游芯片/云巨头 \$260 亿 同步私募内循环，标志着一级市场无约束估值与二线高杠杆算力信贷步入分化高潮。
- 闭源前沿溢价 vs 控制点商品化：继续对照长周期复杂智能体任务（如代码重构、Mythos 网络安全防御、临床跨库查询）与标准化常规任务在客户账单中的留存差异，跟踪开源权重替代率与企业多模型路由对定价权的侵蚀。

### 节点机制与证据锚点

- P / A · 模型能力扩散与稀缺控制点假说：Will Manidis 与 Joe Roberts 在《[The Commanding Heights](https://commanding-heights.com/commanding-heights.pdf)》（[导读](blogs/%E7%A1%85%E8%B0%B7%E6%95%99%E7%88%B6%E8%92%82%E5%B0%94%E9%97%A8%E5%BE%92145%E9%A1%B5%E9%9B%84%E6%96%87%E9%9C%87%E5%8A%A8%E5%8D%8E%E5%B0%94%E8%A1%97%EF%BC%9A%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%8F%AA%E6%98%AF%E5%85%8D%E8%B4%B9%E8%B5%A0%E5%93%81%EF%BC%81%E5%B7%B4%E8%8F%B2%E7%89%B9%E4%B9%B0%E6%8A%A5%E7%A4%BE%E4%BA%8F%E6%8E%8960%25%E7%9A%84%E6%95%99%E8%AE%AD%E6%AD%A3%E5%9C%A8AI%E9%87%8D%E6%BC%94.md)）中提出，若前沿模型能力快速扩散并商品化，经济收益将流向具备监管壁垒、物理资产或独占工作流的“稀缺控制点”。
- B · 前沿闭源模型吸纳预算的对立假说：[前沿闭源模型市场测算](blogs/%E5%89%8D%E6%B2%BF%E9%97%AD%E6%BA%90%E6%A8%A1%E5%9E%8B%E7%9A%84%E5%B8%82%E5%9C%BA%E8%83%BD%E6%9C%89%E5%A4%9A%E5%A4%A7%E3%80%81%E6%B8%97%E9%80%8F%E8%83%BD%E6%9C%89%E5%A4%9A%E5%BF%AB.md)则主张前沿闭源模型可同时凭上限能力与小模型蒸馏性价比持续扩大企业预算份额（依赖算力充足与溢价维持假设）。
- C · 法定实证：Anthropic S-1/A 账本与表外算力租约：[Anthropic 路演纪要全文+PPT 核验导读](blogs/Anthropic%20%E8%B7%AF%E6%BC%94%E7%BA%AA%E8%A6%81%E5%85%A8%E6%96%87%2BPPT.md)（[Anthropic 主体档案](entities/companies/Anthropic.md)）显示，26Q3 收入达 \$169.60 亿（较 25Q1 增 45.1 倍）、年支出超 \$10 万 企业客户逾 11,900 家，短期验证了命题 B 的企业预算吸纳能力；但同时暴露 9M26 研发费用高达 \$192.40 亿（占收入 57.88%，GAAP 营业亏损 -\$12.60 亿），模型厂必须持续将高额推理毛利投入下一代预训练与强化学习军备竞赛，并背负 \$8,954 亿 跨周期租赁承诺。
- S / Q · 研究立场与待验证项：不把“模型商品化”或“闭源通吃”预设为全行业公理，亦不盲信仅扣推理成本的表观高毛利；重点跟踪 27Q1–27Q2 全口径算力利润率能否升破 52% 并实现 GAAP 营业转正、企业 NRR 能否守住高位，以及 \$2,138 亿 附融资/电力条件算力租约的实际通电兑现率。
