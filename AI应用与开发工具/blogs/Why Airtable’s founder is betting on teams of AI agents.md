# Why Airtable’s founder is betting on teams of AI agents

2026-11-17 · Sources (Alex Heath) · 有来源缺口

[本地原件归档](../../../raw/5d25b06e53d6b8e31500414355130c4ae74c8d60fa4880e7afe10e6d88d2e775) · 固定材料版本 `digest-material-5d25b06e53d6b8e31500414355130c4ae74c8d60fa4880e7afe10e6d88d2e775@1` · [一手原站](https://sources.news/p/howie-liu-airtable-hyperagent-bending-spoons)

## 深度拆解与复核

- 口径与利益：本篇基于 Alex Heath 在其科技媒体 [《Sources》播客（2026-11-17）](https://sources.news/p/howie-liu-airtable-hyperagent-bending-spoons) 对 Airtable 创始人兼 Hyperagent 创始人 Howie Liu 的 58m22s 专访全本（赞助方含 Atlassian Jira 及 Teamwork Graph、Granola 与 Mercury/Choice Financial Group/Column NA；Alex Heath 在节目中自述兼任一级市场投资人），并穿透对照 [Bending Spoons S.p.A. 2026-08-04 签约 Form 6-K Ex-99.1](https://www.sec.gov/Archives/edgar/data/2004711/000200471126000009/bsp_ex99-1.htm)、[2026-09-04 交割 Form 6-K Ex-99.1](https://www.sec.gov/Archives/edgar/data/2004711/000200471126000013/bsp_ex99-1.htm) 与 [Bending Spoons 主体档案](../../AI产业与商业/entities/companies/Bending%20Spoons.md)。Howie Liu 的陈述带有明显创始人双重视角激励：既需解释为何在营收逼近 \$500M 且保持增长时以较 2021 年 ZERP 峰值大幅折价出售 Airtable，也需为独立剥离的 Hyperagent 2.0 确立避开巨头红海的多人协同定位。
- ==核心结论==：Airtable 的出售并非财务危机被迫割肉，而是一次“账面净现金兜底清偿 1x 优先清算栈（Pref Stack）、保护普通股股东并剥离 AI 原生团队”的主动架构切分——通过将 \$1.4B+ 累计融资绝大部分留存于账面（交割隐含净现金约 \$965M），Howie Liu 借 [Bending Spoons](../../AI产业与商业/entities/companies/Bending%20Spoons.md) 纪律性并购完成 SaaS 期权兑现，同时将 Hyperagent 2.0 剥离至轻量载体以押注面向非技术 SMB 业主的“多人协同数字员工团队”，直接避开 Meta、OpenAI、Google 与 Anthropic 在 1:1 个人助手赛道的算力补贴肉搏。

### 一、优先清算栈退出、分拆逻辑与 Hyperagent 2.0 多人协同机制

1. 出售 Airtable 的优先清算栈（Pref Stack）与时间期权博弈：Airtable 创立于 2012 年（[Form 6-K 官方公告](https://www.sec.gov/Archives/edgar/data/2004711/000200471126000009/bsp_ex99-1.htm)口径为 2013 年），与 Miro、Dropbox、Evernote 同处早期 B2B SaaS 与 PLG 富浏览器单页应用浪潮，最终服务超 500,000 家组织及 80% 的 Fortune 100 企业。尽管出售时营收逼近 \$500M 且维持现金流健康，Liu 判断 AI 将长期压低按席位收费 SaaS 的估值倍数，拖延不卖本质上是在反向下注“SaaS 倍数不会恶化”（许多 ZERP 期高估值企业最终被迫折价退出或无法续融）。交易得以保护普通股员工的核心前提，在于 Airtable 将累计融资逾 \$1.4B 的绝大部分现金留存账面并用经营现金流补库，从而清偿了投资人 1x 优先清算权（Liu 同时警示背负 2x 优先清算权或债权融资的创业公司极易导致普通股清零），向员工返现并通过 Hyperagent 分拆为老股东保留新业务上行期权。
2. 为什么选择 Bending Spoons 接盘，且不把 Hyperagent 留在 Airtable 内部：买方 [Bending Spoons](../../AI产业与商业/entities/companies/Bending%20Spoons.md)（2026-07-01 登陆纳斯达克，代码 BSP，拥有 Evernote、WeTransfer、Vimeo、Brightcove，并在 2026 年 1 月收购 AOL、3 月收购 Eventbrite，随后收购 Miro）在 S-1 与公开 6-K 中披露了高度透明的并购改造手册——不过度博弈倍数且反垄断风险极低（对比 Figma 与 Adobe 并购被监管拖垮的长周期内耗）。Liu 拒绝母体内孵化的核心依据有二：第一，充沛现金反而干扰从 0 到 1 产品的精致打磨（如 Google+ 坐拥资本与分发仍败给 Facebook）；第二，借 Benchmark 提出的「由内而外（inside-out）vs 由外而内（outside-in）」产品思维（类比 Apple One、Bill Gates 与 Steve Jobs 基于 8086 CPU 定义个人电脑），母体大企业销售惯性会拖慢需要靠高粘性 P99 用户高频反馈推进的迭代节奏，且 AI-native 产品推理算力成本导致默认毛利率远低于传统 SaaS（Liu 引述 Anthropic S-1 显示前沿模型推理虽已有正贡献毛利，但应用层仍须重塑经济账），这与 Sarah Guo 对早期独立 AI 创业窗口的判断一致。
3. Hyperagent 2.0 的 SMB 多人协同架构与避险路线：2025 年底假期，Liu 作为 P99 重度用户在 Claude Code、Cursor Agents 与 Opus 4.5 上重启一线编码，发现前沿模型已超越浅层 Vibecode、能够稳定交付接近资深工程师架构的后端代码，叠加 OpenClaw 验证“用 Agent 构建 Agent”可行性，遂在出售 Airtable 前将项目独立分拆。面对 1:1 个人通用助手赛道已被 ChatGPT Dots、Meta（Mark Zuckerberg 与 Alex / Nat Friedman 等重注数百亿美元算力）、Google、OpenAI、Anthropic、Microsoft 及衍生产品 GrokBot、Instinct、Claude Duet、Muse 挤成“电话亭里的刀战”（knife fight in a phone booth），Alex Heath 将早期多 Agent 配置比作搭建 Sims 与 SimCity；Liu 反思 Hyperagent 1.0 配置项过多（类似早期 OpenClaw 的配置泥潭），正在重做的 Hyperagent 2.0 主攻非技术中小实体企业（SMB）“雇佣一支 AI 同事团队”——每个 Agent 拥有独立账号、身份、权限边界与护栏，支持业主群聊与群语音调度，避免所有角色共用 CEO 邮箱引发越权或泄露。
4. 实体 SMB 垂直工作流与全天候内部 Dogfooding：针对小型保险经纪、园林景观承包商、设计与创意机构，SMB 业主真实痛点在于“雇不起更多全职员工”，而非购买带像素追踪的复杂 CRM。以园林景观承包商（landscaper）为例，Hyperagent 接单研究 Agent 自动调取客户地址卫星图与 Zillow 历史挂牌照片，调用图像模型生成庭院改造效果图，结合技能模板估算工程报价并输出完整方案书，抢在传统竞争对手动辄 5 周回访之前完成转化，再由项目管理 Agent 跟踪每周施工排期与现场物料。在 Hyperagent 内部，Liu 将竞争情报 Agent 接入代码库与开发者讨论，使其夜间自动拆解 5 家竞品截图并直接提交可合并的 PR，或调用视频模型产出广告样片。

| Hyperagent 融资与派现比例 | 分拆后由老股东主导完成“数千万美元”融资 | ⚠️ 信息边界（已登记缺口）：Form 6-K 未拆解 Airtable 优先股清算金额与员工普通股实际净派现比率；Hyperagent 新轮具体估值、融资金额与投资人名单亦未公开。 |

- 本工作台推断：Howie Liu 的退出与再创业是 SaaS 向 Agent 范式迁移的一份清晰资本配置切片——当 AI 推理消耗使应用层天然承受低于纯软件的毛利结构，同时客户开始为“端到端交付营收结果的虚拟雇员”而非“软件席位”付费时，保留旧壳体内高昂研发编制与按席位叙事反而形成负担。但面向园林/保险等非技术 SMB 的真正难点不在单次生成方案，而在多 Agent 跨周履约下的状态持久化、外部工具权限错漏与真实报价误差责任；这与本赛道 T1（长程状态漂移与校验）及 T4（垂直物理工作流须绑死源头报价与线下履约校验）高度同构。

### 观点与可反驳条件

- ==观点==：在传统 SaaS 估值倍数受 AI 压缩的过渡期，保留充沛账面现金的增长期软件公司以清偿 1x 优先清算栈换取退出、并将 AI 原生团队独立剥离轻装攻克 SMB 结果交付型多 Agent 协同，是比在母体内强行做 AI 副驾驶更优的资本配置与组织解耦路径。
- ==推翻条件==：
  1. ① 截至 2027-09-30，若 Hyperagent 2.0 上线后面向园林、保险经纪等非技术 SMB 的 90 天净留存率或付费转化率未见显著起量，且核心阻力来自多 Agent 在真实报价/排期环节的幻觉错漏导致客户退回人工外包，则“SMB 无门槛多人协同 Agent 团队”在当前模型可靠性下尚不成立。
  2. ② 截至 2027-12-31，若 Bending Spoons 在接管 Airtable 后通过 AI 改造与定价重构使 Airtable 连续四个季度保持 20% 以上 ARR 增速且 EBITDA 利润率大幅扩张，或传统 SaaS 巨头（如 ServiceNow、Salesforce）的内部集成式多 Agent 套件在 SMB 与中端市场实现主导性交叉销售，则证明母体分发与现金流对 AI 产品的杠杆价值被 Howie Liu 明显低估。
