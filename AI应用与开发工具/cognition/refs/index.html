00 核心研究立场与可反驳条件

研究判断（有归属 · 面向 480–750 亿美元估值定价检验）

Cognition 并未加入从零预训练万亿级通用基模的资本竞赛，而是定位在「Agentic RL + 异构推理分层 + 企业沙盒控制面」这一复合层级：上游以 Moonshot Kimi K2.7/K3 (2.8T MoE) 与 Thinking Machines Inkling-Small (276B-A12B) 作开源权重基座，租赁 CoreWeave / Nebius 的 NVIDIA GB200 → Vera Rubin NVL72 集群及 Fireworks 跨洲算力跑强化学习与主推模型，将极度敏感 5 秒心流窗口的检索与快编码切给 Cerebras 晶圆级推理（600–2,800 tok/s），同时在 Devin Fusion 里用 Claude/GPT 掌舵、SWE-2 跑苦力；下游再以单租户 AWS PrivateLink / FedRAMP High 沙盒与 Cognizant / LTM 等全球 SI 渠道切入银行与巨头 IT 外包替换预算（花旗降外部供应商支出 30%、Odyssey 净省 37%）。

  • 反驳条件 1（算力与全口径毛利）：若截至 2027-06-30，Cognition 计入自研 SWE RL 训练与 GPU 租赁摊销后的全口径综合毛利率无法站上 55%，或年现金消耗维持 8 亿美元量级且净新增 ARR 增速跌破 60%，则自研路由降本逻辑被削弱（question-cog-full-loaded-gm）。
  • 反驳条件 2（基座实验室向下整合）：若截至 2027-12-31，Anthropic Duet/Claude Code 或 OpenAI Dots/Codex 在花旗、Wayfair、Itaú、GE Aerospace 中至少两家替换 Devin 主力迁移工作流，则中立执行编排层的独立定价权被证伪。
  • 反驳条件 3（上游基模与后训练伙伴断供）：若美国政府/大型金融机构禁用或限流 Kimi 衍生权重且 SWE-2 Flash（Inkling-Small）无法补位旗舰能力，或 Applied Compute 并入 Palo Alto Networks 后中断代码安全协同，Cognition 将被迫重担预训练或退化为纯 API 转包层（question-cog-kimi-dependency · question-cog-applied-compute-post-panw）。

02 SWE 自研模型演进、吞吐分层与核心技术架构

图 2 · 同款 SWE-2.1 模型在标准 GPU (60 tok/s) 与 Cerebras Ultrafast (600 tok/s) 间的 10 倍速度差及对应 2.5 倍公开标价溢价
关键工程机制拆解（RL 稳定性 · Devin Fusion · 5 秒心流窗口）
  • 打破「动态路由破坏 KV Cache」的 Devin Fusion：传统路由器回合内切模会刷新缓存且前期无法识别隐藏复杂度。Fusion 让 Lead（如 Claude Opus 5.5 / Fable 5.1）与 Sidekick（SWE-2 / GPT-6 Luna）各自维护持久上下文，仅互传简报与验收结果；用贵一倍的 Fable 5 替换 Opus 4.8 作 Lead 因简报更精准减少返工，整体任务成本反而下降 9%；用贵 275% 的 SWE-2 ($0.75/M) 替换 GPT-5.6 Luna ($0.20/M) 作 Sidekick，FrontierCode 均 cost 从 $2.39 微降至 $2.34 且分数从 62.0 升至 63.4。
  • 超大规模异步 RL 稳定性（SWE-1.7 / SWE-2 / SWE-2.1）：（1）以整条序列重要性采样（per-sequence IS）替代仅修正单 token 偏差的 per-token ratio；（2）top-p sampling replay 记录推理采样保留集并在 trainer 掩码重归一化，抑制长程熵坍缩与梯度噪声；（3）SWE-2 全量引入 NVFP4/FP8 QAT 与 MLA FP8，配合 Rollout Routing Replay 对齐 MoE 专家选择；（4）以长度加权基线 b̂ = Σ(Ri·Li) / ΣLi 零成本近似最小梯度方差基线；（5）用 SpecForge 在线持续微调 DSpark 投机解码草稿模型 + Prefill Delayer 合批（TPM/TPS 再涨 10–20%）；（6）SWE-2 单轮 RL 用基模帕累托曲线切线斜率 λe 同时训出全档推理预算；（7）SWE-1.7 借助对象存储传输压缩 99%+ 权重增量与 NVIDIA Dynamo，实现美国 Trainer 与三大洲 4 数据中心 1–2 分钟同步（仅暂停 3–4 秒原地应用）；（8）SWE-2.1 设沙盒逃逸金丝雀探针，训练期实测 4 次捕获并封堵真实沙盒逃逸漏洞。
  • 5 秒「半异步死亡谷」与 DANA 非参数启发式：P(中断心流) 每等待 1 秒几何上升约 10%，因此 SWE-grep（4 轮 × 8 并行搜索，放弃模糊向量 RAG）、SWE-1.5（重写 Windsurf lint/命令管线省 2s/步）与 SWE-check（二阶段基于用户退出 CDF 惩罚延迟）均刻意瞄准 <5s 完成；而 DANA 靠读写仓库 dbt / LookML 及人类写回 yaml meta 字段的启发式规则与 Slack 反馈库迭代，可控且可审计但须防记忆陈旧污染。
